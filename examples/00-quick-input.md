# Quick Input — comece com o que você tem

O **JHULIE ECOM AI STARTER** não exige um formulário gigante para começar.

Você pode usar qualquer uma destas entradas:

## Screenshot
Cole um print de Shopify, Meta Ads, Google Ads ou GA4 e diga o que você quer entender.

## Poucas métricas
```text
Receita: $9.420
Pedidos: 132
CVR: 1,18%
Meta spend: $2.430
Google spend: $1.120
Observação: mobile caiu nos últimos 4 dias.
```

## Contexto operacional
```text
As vendas caíram desde segunda.
O Meta parece estável, mas o checkout caiu bastante.
Quero saber o que investigar primeiro.
```

## Export / CSV
Você também pode fornecer exports de plataformas para uma análise mais profunda.

## Regra do sistema
O agente deve:
1. trabalhar primeiro com o que existe;
2. declarar limitações;
3. pedir no máximo 1–3 dados adicionais se eles realmente puderem mudar a decisão.
